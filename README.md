# Инструмент визуализации графа зависимостей (Вариант №1)

## 1. Общее описание
Данный проект представляет собой инструмент командной строки (CLI)
для сбора, анализа и визуализации графа зависимостей пакетов Python (pip)
без использования сторонних библиотек и пакетных менеджеров.

Проект разработан в рамках практической работы по дисциплине
«Конфигурационное управление» (МИРЭА, ИКБО-51-25, Вариант №1).

Основные возможности:
- Конфигурирование параметров через JSON-файл.
- Сбор прямых зависимостей пакетов через PyPI JSON API / wheel METADATA.
- Построение полного транзитивного графа зависимостей с помощью рекурсивного DFS.
- Ограничение максимальной глубины обхода и фильтрация по подстроке.
- Корректная обработка и детектирование циклических зависимостей.
- Поддержка тестового режима (графы с именами пакетов в виде заглавных букв).
- Вычисление порядка загрузки/установки зависимостей (топологический порядок).
- Формирование диаграммы зависимостей на языке PlantUML и рендеринг изображения.
- Сравнение результатов с реальными менеджерами и утилитами (pip, pipdeptree).

## 2. Описание всех функций и настроек

### 2.1. Конфигурационные параметры (JSON)
Конфигурация передается через JSON-файл (по умолчанию `config.json`):
- `package_name` (строка): имя анализируемого пакета (например, `"requests"`).
- `repository_url` (строка): базовый URL репозитория или путь к файлу тестового репозитория.
- `test_mode` (логический): `true` для работы с тестовым файлом, `false` для реального PyPI.
- `package_version` (строка): анализируемая версия пакета (например, `"2.31.0"`).
- `max_depth` (целое неотрицательное число): глубина раскрытия графа зависимостей.
- `filter_substring` (строка): подстрока для исключения пакетов из анализа.

### 2.2. Основные модули и функции
- `src.config`: валидация и загрузка параметров конфигурации.
- `src.collector`: сбор прямых зависимостей без сторонних пакетов.
- `src.graph`: рекурсивный алгоритм DFS для построения графа с учетом глубины, циклов и фильтрации.
- `src.order`: расчет порядка загрузки зависимостей (обратный топологический порядок / post-order).
- `src.visualizer`: генерация текстового описания PlantUML и рендеринг изображения (PNG/SVG).
- `src.main`: точка входа CLI с поддержкой выбора этапа (`--stage 1..5`).

## 3. Описание команд для сборки проекта и запуска тестов

### Сборка и окружение
Проект реализован на стандартной библиотеке Python 3.10+ и не требует установки сторонних зависимостей.

### Запуск приложения
Windows (через bat-скрипт):
```cmd
run.bat
run.bat --config config.json
run.bat --config config.json --stage 1
```

Linux / macOS (через sh-скрипт):
```bash
chmod +x run.sh
./run.sh
./run.sh --config config.json --stage 1
```

Прямой запуск через интерпретатор Python:
```bash
python -m src.main --config config.json
```

### Запуск тестов
Windows:
```cmd
run.bat test
```

Linux / macOS:
```bash
./run.sh test
```

Или напрямую через unittest:
```bash
python -m unittest discover -s tests -p "test_*.py" -v
```
